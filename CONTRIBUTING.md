# Contributing

Corrections and improvements are welcome.

## What to contribute

- Fix factual or mathematical errors, with a short explanation or source.
- Improve clarity without changing the intended meaning.
- Correct typos, formatting and broken links.
- Add original diagrams or examples that make a concept easier to understand.

## Pull request workflow

1. Open an issue first for a substantial change so the scope can be discussed.
2. Fork the repository and create a focused branch.
3. Keep each pull request limited to one topic or a closely related group of corrections.
4. Explain what changed and why.
5. Check Markdown links, LaTeX delimiters and image paths before submitting.

## Content and attribution

Submit only material that you created or are authorised to contribute. Do not copy course slides, textbook passages, proprietary diagrams or another person's notes without permission. Cite sources for factual or mathematical additions where appropriate.

Clearly distinguish a correction to a source transcription from an additional explanation.

## Copyright

Submitting a pull request does not automatically transfer copyright in your contribution to the repository owner. For substantial contributions, the maintainer may request a separate written contributor agreement before merging. Do not submit a contribution unless you are willing to discuss the applicable terms.
